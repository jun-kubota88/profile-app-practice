## 概要
COACHTECH 教材 Tutorial 9-1「Laravel基礎ハンズオン」で作成した成果物です。

## 使用技術
- PHP 8.x
- Laravel 10.x
- Blade テンプレート

## 学んだこと
- Laravel の「ルーティング → コントローラー → ビュー」の基本フロー
- Blade テンプレートでの変数表示（{{ $name }}）と @foreach ループ
- コントローラーからビューへのデータ受け渡し（view() の第2引数）
